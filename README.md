# MoneyMap

MoneyMap — адаптивний вебзастосунок для особистих фінансів. Його головна ідея: не перетворювати користувача на бухгалтера, а дати коротку й чесну відповідь на три щоденні питання — скільки грошей доступно, куди вони йдуть і чи вистачає темпу для запланованих цілей.

## Що реалізовано

- публічна продуктова сторінка та інтерактивний демо-режим;
- реєстрація, вхід і вихід через захищену авторизацію ChatGPT;
- приватний дашборд із балансом, місячною динамікою та структурою витрат;
- таблиця транзакцій із пошуком, фільтрами, додаванням і редагуванням;
- CSV імпорт та експорт із підтримкою лапок і ком у значеннях;
- бюджети за категоріями з прогресом, залишком і прогнозом;
- фінансові цілі з дедлайном, прогресом і поповненням;
- повна мобільна адаптація, нижня навігація та touch-friendly дії;
- серверна перевірка власника кожної операції та D1-персистентність.

## Модель даних

- `users`: профіль, email, ім’я для відображення, валюта;
- `categories`: особисті категорії доходів і витрат, колір та іконка;
- `transactions`: сума в центах, дата, тип, категорія, опис, джерело і нотатка;
- `budgets`: місячний ліміт для категорії; унікальна пара користувач + категорія + місяць;
- `goals`: цільова й поточна сума, дедлайн, статус і візуальне оформлення.

Грошові значення зберігаються як цілі числа в центах, щоб уникати помилок дробової арифметики. Індекси покривають основні сценарії вибірки: транзакції за користувачем і датою, витрати за категорією, бюджети за місяцем та активні цілі за дедлайном.

## Локальний запуск

```bash
npm install
npm run dev
```

Збірка й перевірка:

```bash
npm run build
npm test
```

Міграції D1 генеруються командою `npm run db:generate` і зберігаються в `drizzle/`.

## CSV формат

```text
date,type,category,description,merchant,amount,note
2026-08-10,expense,Продукти,Покупки на тиждень,Billa,86.40,
```

`type` приймає `income` або `expense`; назва категорії має збігатися з категорією профілю.

## Стек

React 19, Vinext, TypeScript, Cloudflare Workers, D1 SQLite, Drizzle ORM і Sites hosting.
